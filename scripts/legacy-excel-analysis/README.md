# Análises históricas de planilhas

Scripts utilizados durante o levantamento e a conferência das planilhas Excel que deram origem ao sistema. Eles não participam do build, da produção ou das rotinas normais de manutenção.

Os scripts esperam arquivos locais em `referencias/`, que é ignorada pelo Git para impedir o envio de dados operacionais. Alguns exigem Python e `openpyxl`.

Mantenha esta pasta somente como referência histórica. Novas rotinas operacionais devem ser criadas em `scripts/` com validação de argumentos e documentação própria.
